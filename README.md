# Backend Basics

Учебный проект для знакомства со структурой Python-проекта.

## Требования

- Python 3.12

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Проверка кода

```bash
ruff check .
ruff format .
```
